Supercharge your Docs.

Embed a full Turbo C graphics environment in your website with one line of code. Perfect for tutorials, blogs, and educational resources.

PostMessage API

Send code snippets directly from your page logic via standard messaging.

Quick Start

01

Initialize the Iframe

Place this hidden iframe in your page. Use /embed as the source.

html
<iframe id="gh-embed" 
        src="/embed" 
        width="640" height="480" 
        style="border:0; background:#000; display:none;">
</iframe>
02

Trigger the Execution

Show the iframe and send the code snippet using postMessage.

javascript
function runCode(code) {
  const embed = document.getElementById('gh-embed');
  embed.style.display = 'block';
  
  // Send code snippet
  embed.contentWindow.postMessage({
    type: 'RUN_SNIPPET',
    snippet: code
  }, '*');
}

Message Interface

The messaging API allows for both snippet-based (auto-wrapped) and full-program execution.

Property Type Details
type String Must be "RUN_SNIPPET".
snippet String Your C/C++ code.
boilerplate Bool Optional. Set to false to disable main() wrapping behavior.

Pro Tip

If boilerplate is true (default), the runner automatically injects #include <graphics.h> and initializes the BGI driver for you.

Layout Customization

The DOS canvas is fixed at 640x480. To integrate it into your site's responsive design, use CSS scaling on the container.

css
/* Scalable wrapper example */
#embed-wrapper {
  --embed-scale: 0.8; /* 80% scale */
  width: calc(640px * var(--embed-scale));
  height: calc(480px * var(--embed-scale));
  overflow: hidden;
  border-radius: 12px;
}
