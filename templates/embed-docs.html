graphics.h Embed API

Embed a full Turbo C graphics runtime directly into your website using a simple JavaScript SDK.

Run circle(x, y, r) snippets or full C/C++ programs inside a secure browser-based DOS environment, no installation required.

  • No NPM packages
  • No backend required
  • Runs entirely in the browser
  • Works in documentation, blogs, and courses

What Is the Embed API?

The Embed API allows you to integrate the graphics.h runtime into any website using:

  • An iframe
  • A lightweight SDK
  • Or direct URL parameters

It is ideal for:

  • Programming tutorials
  • Documentation websites
  • Coding courses
  • Interactive blog posts
  • Online coding platforms

Instead of showing static screenshots, you can show live, editable graphics programs.

The runtime runs inside an isolated iframe and communicates securely with your page using JavaScript.

Quick Start (3 Steps)

  1. Include the SDK
  2. Create a Container
  3. Initialize and Run
html
<script src="https://graphics-h-compiler.vercel.app/sdk.js"></script>
<div id="gh-container"></div>
<script>
  const gh = new GraphicsHEmbed("#gh-container", {
    baseUrl: "https://graphics-h-compiler.vercel.app",
    scale: 0.75
  });

  gh.runSnippet("setcolor(YELLOW); circle(320, 240, 80);");
</script>

That's it.

Snippet Mode (Default)

Snippet mode is designed for documentation-style examples.

You only provide the core graphics code:

c
setcolor(GREEN);
rectangle(200, 150, 440, 330);
outtextxy(260, 350, "rectangle demo");

The system automatically injects:

  • #include <graphics.h>
  • initgraph()
  • closegraph()
  • Required boilerplate

Snippet mode is enabled by default.

Full Program Mode

If you want full control, disable boilerplate injection.

javascript
const fullCode = `
#include <graphics.h>
#include <conio.h>

int main() {
    int gd = DETECT, gm;
    initgraph(&gd, &gm, "");

    setcolor(WHITE);
    circle(320, 240, 100);

    getch();
    closegraph();
    return 0;
}
`;

gh.runSnippet(fullCode, { boilerplate: false });

Use this when:

  • Teaching full Turbo C programs
  • Demonstrating main() structure
  • Showing legacy-style BGI programs

SDK Reference

Constructor

new GraphicsHEmbed(selector, options)

Parameters

Parameter Type Description
selector string CSS selector for container (#id or .class)
options object Optional configuration

Options

Option Type Description
baseUrl string Base URL of runtime
scale number Output scaling (0.5 – 2.0)
boilerplate boolean Enable or disable automatic boilerplate
baseWidth number Base canvas width
baseHeight number Base canvas height
theme string Theme configuration

Methods

runSnippet(code, options?)

Compiles and runs code.

js
gh.runSnippet("circle(320, 240, 80);");

Use { boilerplate: false } for full programs.

runProgram(fullCode)

Runs a complete C/C++ source file. Equivalent to:

js
gh.runSnippet(code, { boilerplate: false });

setScale(scale)

Dynamically rescale the DOS output while preserving the 4:3 aspect ratio.

js
gh.setScale(1.2);

Responsive Layout

The embed automatically scales, but you can control layout using CSS.

css
.embed-container {
  position: relative;
  width: 100%;
  max-width: 640px;
  aspect-ratio: 4 / 3;
}

.embed-container iframe {
  width: 100%;
  height: 100%;
  border: 0;
}

This ensures the runtime maintains the classic 640×480 4:3 ratio.

URL-Based Autorun (Optional)

You can also pre-load code via URL parameters for shareable examples.

Example use cases:

  • Share a live demo link
  • Embed interactive examples in blog posts
  • Provide pre-filled exercises for students

Why Embed Instead of Screenshot?

Static images:

  • Cannot be edited
  • Cannot be explored
  • Do not teach experimentation

The Embed API provides:

  • Live execution
  • Editable code
  • Instant visual feedback
  • Real Turbo C behavior

This turns passive readers into active learners.
