About This Project

graphics.h is a legacy graphics library still taught in many Computer Graphics courses. However, running it requires outdated tools like Turbo C and DOSBox.

This project solves that problem by providing a modern, web-based compiler that runs graphics.h programs instantly in your browser.

About Legacy-Main Branch:
This is the core compiler branch focused solely on functionality. It provides the essential graphics.h compilation and execution environment without any additional features like analytics, SEO optimization, or marketing elements. This branch serves as the foundation of the compiler's technical implementation.
