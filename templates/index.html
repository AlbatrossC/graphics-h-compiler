Why graphics.h?

The Modern Way to Learn C Graphics Programming

The graphics.h header file is part of the legacy Borland Graphics Interface (BGI). Traditionally, students had to install outdated 1990s software like Turbo C++ and DOSBox. This graphics.h online compiler removes that barrier entirely.

Run in Your Browser

Write code and execute instantly. Functions like initgraph() and circle() work seamlessly, creating a perfect online compiler environment.

Zero Setup Required

Skip the 90s software setup. No DOSBox configuration, no missing BGI compiler settings. Simply code online and let our WebAssembly engine handle graphicsh execution.

VS Code Integration

Prefer local IDEs? Our VS Code graphics extension brings one-click graphics.h compiling right to your editor. A seamless code extension for modern developers.

Designed for SPPU

Built with SPPU Computer Graphics labs in mind. Easily implement algorithms like DDA, Bresenham's, and flood fill. Your complete Turbo C online alternative.

Why This Exists

graphics.h is a legacy graphics library still taught in Computer Graphics courses—especially in SPPU curriculum. But running it today requires jumping through hoops: installing Turbo C, configuring DOSBox, dealing with broken environments.

Students waste hours fighting setup instead of learning graphics programming.

This project eliminates that friction.

It provides two ways to run graphics.h programs instantly:

  • Online compiler – Works directly in your browser
  • VS Code extension – Integrates with your local development environment

No legacy tools. No manual configuration. Just write code and run it.

Built by an SPPU student who experienced this pain firsthand. The goal is simple: let students focus on learning graphics, not wrestling with 1990s software.
