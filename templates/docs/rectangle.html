rectangle()

Drawing Function
Primitive

The rectangle() function in graphics.h is used to draw rectangles using two opposite corner coordinates in Turbo C BGI graphics. It pairs with setcolor() for border colors and floodfill() for filling, making it essential for creating boxes, borders, and shapes in DOS graphics programming.

Description

The rectangle() function draws a rectangle outline using the current drawing color and line style. The rectangle is defined by two opposite corners: the top-left corner (left, top) and the bottom-right corner (right, bottom), making it a fundamental shape primitive for BGI graphics programs.

Syntax

C 
void rectangle(int left, int top, int right, int bottom);

Parameters

  • left
    The x-coordinate of the top-left corner.
  • top
    The y-coordinate of the top-left corner.
  • right
    The x-coordinate of the bottom-right corner.
  • bottom
    The y-coordinate of the bottom-right corner.

Complete Example

C 
#include 
#include 

int main() {
    int gd = DETECT, gm;
    initgraph(&gd, &gm, "");
    
    // Draw a green rectangle
    setcolor(GREEN);
    rectangle(150, 100, 490, 320);
    
    // Draw a smaller red rectangle inside
    setcolor(RED);
    rectangle(200, 150, 440, 270);
    
    // Draw a blue rectangle outline
    setcolor(BLUE);
    rectangle(250, 180, 390, 240);
    
    getch();
    closegraph();
    return 0;
}

Tip: To draw a filled rectangle, use bar() for a 2D filled rectangle or bar3d() for a 3D filled rectangle with depth.

Frequently Asked Questions

How do I draw a filled rectangle in graphics.h?

To draw a filled rectangle, use the bar() function which draws a filled rectangular bar using the current fill style and color. For 3D filled rectangles with depth, use bar3d(). Alternatively, you can use rectangle() followed by floodfill() to fill the interior with a color.

What coordinates does rectangle() use?

The rectangle() function uses four integer parameters: left (x-coordinate of top-left corner), top (y-coordinate of top-left corner), right (x-coordinate of bottom-right corner), and bottom (y-coordinate of bottom-right corner). The rectangle is drawn as an outline only, not filled.

How do I change the border color of a rectangle?

Use the setcolor() function before calling rectangle() to set the border color. For example, setcolor(YELLOW) will make the rectangle border appear in yellow. The default border color is WHITE.

What's the difference between rectangle() and bar()?

rectangle() draws only the outline/border of a rectangle using the current line color. bar() draws a solid filled rectangle using the current fill style and fill color. Use rectangle() for outlined boxes and bar() for filled areas.

Can I draw rectangles with rounded corners using rectangle()?

No, the rectangle() function only draws rectangles with sharp 90-degree corners. To draw rounded rectangles, you would need to combine multiple arc() or ellipse() calls at the corners with line() calls for the sides.
