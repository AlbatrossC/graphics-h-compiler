initgraph()

Lifecycle Function
Initialization

The initgraph() function in graphics.h is used to initialize the BGI graphics system in Turbo C programming. It loads the graphics driver and switches the display to graphics mode, enabling you to use drawing functions like line(), circle(), and rectangle().

Description

The initgraph() function initializes the graphics system by loading a graphics driver from disk and putting the system into graphics mode. This function must be called before any other graphics operations can be performed. It sets up the video mode, allocates memory for the graphics buffer, and prepares the drawing environment.

When DETECT is specified as the graphics driver, the function automatically detects the best available graphics driver and mode for the hardware. Always pair initgraph() with closegraph() to properly release graphics resources when done.

Syntax

C 
void initgraph(int *graphdriver, int *graphmode, const char *pathtodriver);

Parameters

  • graphdriver
    Pointer to an integer that specifies the graphics driver to use. Use DETECT for automatic detection, or specify a driver constant (CGA, EGA, VGA, etc.). After the call, this variable contains the actual driver that was loaded.
  • graphmode
    Pointer to an integer that specifies the graphics mode. If DETECT is used, this is set to the highest available mode for the detected driver. Otherwise, specify a mode constant (VGALO, VGAMED, VGAHI, etc.).
  • pathtodriver
    String specifying the directory path where BGI driver files are located. Use an empty string "" if drivers are in the current directory.

Return Value

This function does not return a value. If initialization fails, an error code can be retrieved using graphresult().

Example Implementation

C 
#include 
#include 
#include 

int main() {
    int gd = DETECT, gm;
    char driverPath[] = "";
    
    // Initialize graphics mode
    initgraph(&gd, &gm, driverPath);
    
    // Check for initialization errors
    int error = graphresult();
    if (error != grOk) {
        printf("Graphics error: %s\n", grapherrormsg(error));
        return 1;
    }
    
    // Display information about the graphics mode
    setcolor(WHITE);
    outtextxy(10, 10, "Graphics initialized successfully!");
    
    // Draw a simple rectangle
    rectangle(100, 100, 540, 380);
    
    getch();
    closegraph();
    return 0;
}

Error Handling

Always check for errors after calling initgraph(). Common error codes include:

  • grOk (0)
    No error - graphics initialized successfully.
  • grNoInitGraph (-1)
    Graphics not initialized - BGI not installed.
  • grNotDetected (-2)
    Graphics hardware not detected.
  • grFileNotFound (-3)
    Driver file not found - check the path parameter.
  • grInvalidDriver (-4)
    Invalid driver number specified.
  • grNoLoadMem (-5)
    Not enough memory to load driver.

Best Practice: Always pair initgraph() with closegraph() to properly release graphics resources. Use getch() or similar before closegraph() to keep the graphics window visible.

Note: When using DETECT, the function modifies the values pointed to by graphdriver and graphmode to reflect the detected hardware configuration.

Frequently Asked Questions

What happens if I don't call initgraph()?
Without calling initgraph(), your program remains in text mode and all graphics functions will fail. The graphics system must be initialized before using any drawing functions like line(), circle(), or rectangle().
What is DETECT in initgraph?
DETECT is a constant that tells initgraph to automatically detect the best available graphics driver on your system. It will choose VGA, EGA, or CGA based on what's available.
Do I need to call closegraph() after initgraph()?
Yes, always pair initgraph() with closegraph() to properly release graphics resources and return to text mode. Failing to do so may cause memory leaks or leave the display in graphics mode.
What graphics drivers are supported?
BGI supports CGA, MCGA, EGA, EGA64, EGAMONO, VGA, HERCMONO, ATT400, PC3270, and IBM8514. VGA is the most commonly used and provides 640x480 resolution with 16 colors.
How do I check if initgraph() failed?
Use graphresult() immediately after initgraph() to check for errors. If it returns grOk (0), initialization was successful. Other values indicate specific errors like missing drivers or insufficient memory.
