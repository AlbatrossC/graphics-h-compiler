Fill and Patterns

Fill Styles & Patterns in graphics.h

Filling is controlled by style and color. This page shows how setfillstyle() and setfillpattern() affect bar(), fillellipse(), fillpoly(), and floodfill().

setfillstyle()

void setfillstyle(int pattern, int color);

Sets the fill pattern and fill color for subsequent filled drawing operations.

setfillstyle(SOLID_FILL, LIGHTGREEN);
bar(80, 80, 220, 180);

Common Fill Styles

  • SOLID_FILL: Fully solid region.
  • LINE_FILL, LTSLASH_FILL, SLASH_FILL: line-based textures.
  • HATCH_FILL, XHATCH_FILL: crosshatch effects.
  • WIDE_DOT_FILL, CLOSE_DOT_FILL: dotted fills.
  • USER_FILL: custom pattern via setfillpattern().

setfillpattern()

void setfillpattern(char pattern[8], int color);

Creates an 8x8 custom bit pattern. Each byte controls one row of pixels in the fill tile.

char bricks[8] = {0xFF,0x81,0xBD,0x81,0xFF,0x81,0xBD,0x81};
setfillpattern(bricks, LIGHTRED);

Example Program

#include <graphics.h>
#include <conio.h>

int main() {
    int gd = DETECT, gm;
    initgraph(&gd, &gm, "");

    setcolor(WHITE);

    setfillstyle(SOLID_FILL, GREEN);
    fillellipse(120, 120, 60, 40);

    setfillstyle(HATCH_FILL, YELLOW);
    bar(220, 70, 360, 180);

    char custom[8] = {0xAA,0x55,0xAA,0x55,0xAA,0x55,0xAA,0x55};
    setfillpattern(custom, LIGHTMAGENTA);
    rectangle(390, 70, 540, 180);
    floodfill(400, 80, WHITE);

    getch();
    closegraph();
    return 0;
}

Practical Tips

  • Set fill style just before the shape you fill to avoid accidental reuse.
  • Use strong outline color for floodfill() boundaries.
  • Prefer simpler patterns when drawing many shapes for better readability.
