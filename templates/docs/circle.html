circle()

Primitive Component
Drawing Function

Description

The circle() function draws a circular boundary with a defined radius at a specific center point. The circle is drawn using the current drawing color (default is WHITE) and line style.

Syntax

C 
void circle(int x, int y, int radius);

Parameters

  • x
    The x-coordinate of the center point (horizontal position).
  • y
    The y-coordinate of the center point (vertical position).
  • radius
    The radius of the circle in coordinate units (pixels).

Example Implementation

C 
#include <graphics.h>

int main() {
    int gd = DETECT, gm;
    initgraph(&gd, &gm, "");

    // Draw three concentric circles
    setcolor(YELLOW);
    circle(320, 240, 50);
    circle(320, 240, 75);
    circle(320, 240, 100);

    getch();
    closegraph();
    return 0;
}
