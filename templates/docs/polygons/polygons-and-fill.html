Polygons and Fill

Polygons & Fill in graphics.h

This section covers polygon drawing and filling with drawpoly(), fillpoly(), and floodfill(). Use these functions for custom shapes that are not simple rectangles or circles.

Core Functions

void drawpoly(int numpoints, int* polypoints);
void fillpoly(int numpoints, int* polypoints);
void floodfill(int x, int y, int border);
  • drawpoly(): Draws only polygon edges.
  • fillpoly(): Draws and fills polygon using the active fill style.
  • floodfill(): Fills an enclosed area starting from a seed point.

Point Array Format

For polygon functions, coordinates are passed as alternating x, y values.

int pts[] = {100,120, 200,80, 280,160, 150,220};  // 4 points
drawpoly(4, pts);

numpoints is the number of points, not the number of integers in the array.

drawpoly() Example

#include <graphics.h>
#include <conio.h>

int main() {
    int gd = DETECT, gm;
    initgraph(&gd, &gm, "");

    int p1[] = {120, 120, 220, 90, 300, 160, 180, 240};
    setcolor(WHITE);
    drawpoly(4, p1);

    getch();
    closegraph();
    return 0;
}

fillpoly() Example (Runnable)

#include <graphics.h>
#include <conio.h>

int main() {
    int gd = DETECT, gm;
    initgraph(&gd, &gm, "");

    int p2[] = {90, 200, 180, 100, 280, 160, 240, 270, 120, 280};
    setcolor(YELLOW);
    setfillstyle(SOLID_FILL, LIGHTBLUE);
    fillpoly(5, p2);

    getch();
    closegraph();
    return 0;
}

floodfill() Example

Use floodfill() after drawing a closed boundary.

setcolor(WHITE);
rectangle(80, 80, 280, 220);
setfillstyle(HATCH_FILL, GREEN);
floodfill(100, 100, WHITE);

If the border color argument does not match the actual boundary color, fill may leak or fail.

Common Mistakes

  • Passing wrong numpoints value.
  • Using an open shape with floodfill().
  • Forgetting setfillstyle() before fillpoly().
  • Using an incorrect border color in floodfill().
