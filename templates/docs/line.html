line()

Drawing Function
Primitive

The line() function in graphics.h is the fundamental drawing primitive used to draw straight lines between two points in Turbo C graphics programs. It works with setcolor() to control line color and pairs with functions like circle() and rectangle() to create complex BGI graphics drawings.

Description

The line() function draws a straight line between two specified points using the current drawing color and line style. The line includes both endpoints (x1, y1) and (x2, y2), making it ideal for creating precise graphics in BGI graphics programming.

Syntax

C 
void line(int x1, int y1, int x2, int y2);

Parameters

  • x1
    The x-coordinate of the starting point.
  • y1
    The y-coordinate of the starting point.
  • x2
    The x-coordinate of the ending point.
  • y2
    The y-coordinate of the ending point.

Complete Example

C 
#include 
#include 

int main() {
    int gd = DETECT, gm;
    initgraph(&gd, &gm, "");
    
    // Draw a yellow diagonal line
    setcolor(YELLOW);
    line(100, 100, 540, 380);
    
    // Draw a red horizontal line
    setcolor(RED);
    line(100, 240, 540, 240);
    
    // Draw a green vertical line
    setcolor(GREEN);
    line(320, 50, 320, 430);
    
    getch();
    closegraph();
    return 0;
}

Tip: Use setcolor() before calling line() to change the line color. The default color is WHITE.

Frequently Asked Questions

How do I change the color of a line in graphics.h?

Use the setcolor() function before calling line() to set the drawing color. For example, setcolor(RED) or setcolor(YELLOW) will make subsequent lines appear in that color. The default color is WHITE if not specified.

Does the line() function include both endpoints?

Yes, the line() function draws a line that includes both the starting point (x1, y1) and the ending point (x2, y2). The pixels at both coordinates are part of the drawn line.

Can I draw dashed or dotted lines using line()?

The line style (solid, dashed, dotted, etc.) is controlled by setlinestyle() function, not by line() itself. Call setlinestyle() before line() to change the line pattern. The default is a solid line.

How do I draw a line relative to the current position?

Use the linerel() function to draw a line relative to the current graphics cursor position, or lineto() to draw a line from the current position to an absolute coordinate. The line() function always uses absolute coordinates.

What happens if I draw a line outside the graphics window?

Lines drawn partially outside the graphics window will be clipped to the visible area. However, coordinates far outside the valid range may produce unexpected results. It's best to keep coordinates within the range of 0 to getmaxx() for x and 0 to getmaxy() for y.
