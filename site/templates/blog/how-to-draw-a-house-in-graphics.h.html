How to Draw a House in graphics.h

Drawing a house is one of the best beginner exercises in C graphics programming. It uses straight lines, rectangles, triangles, circles, colors, and fills in one small program, so you get practical experience with the core graphics.h drawing functions.

By AlbatrossC Updated May 28, 2026 15 minute tutorial Beginner friendly

What you will build

You will create a simple scene with a house body, roof, door, windows, sun, ground, and a few decorative details. The program runs in the graphics.h online compiler and also works in Turbo C or WinBGI style setups with small path changes.

Quick answer:

To draw a house in graphics.h, initialize graphics mode with initgraph(), draw the house body with bar() or rectangle(), create the roof with three line() calls, fill closed areas with floodfill(), and add details such as windows, a door, and the sun using simple coordinates.

1. Understand the House Drawing Concept

A computer graphics screen is a grid of pixels. In most classic graphics.h examples, the top-left corner is coordinate (0, 0). The x-coordinate increases as you move right, and the y-coordinate increases as you move down. This is different from the coordinate plane used in math class, so it is worth remembering before you start drawing.

A simple house can be broken into basic shapes. The main wall is a rectangle. The roof is a triangle made with three lines. The door is another rectangle. The windows are small rectangles or squares. The sun is a circle, and the ground can be a long line or filled rectangle. Once you think in shapes, the program becomes easy to plan.

For this tutorial, the house body starts at x = 180 and y = 220. The body ends at x = 460 and y = 420. That gives enough room for the roof above it and the ground below it. You can change these numbers later to move or resize the house.

2. graphics.h Functions Used in This Program

The program uses a small group of common functions. If you understand these, you can draw many beginner graphics scenes.

initgraph()
Starts graphics mode. In many online compilers, the driver path is handled for you.
setcolor()
Selects the outline color used by drawing commands like line(), rectangle(), and circle().
setfillstyle()
Chooses the fill pattern and fill color for shapes.
bar()
Draws a filled rectangle. It is useful for walls, doors, windows, and the ground.
line()
Draws a straight line between two points. Three lines can form the roof triangle.
circle()
Draws a circle. Here it is used for the sun and the door knob.
floodfill()
Fills an enclosed area with the current fill style. It is used for the roof.

3. Complete C Program to Draw a House in graphics.h

Paste the following program into the graphics.h online compiler, click run, and you should see the house scene. The code is intentionally written with clear coordinates so it is easy to edit.

#include <graphics.h>
#include <conio.h>

int main()
{
    int gd = DETECT, gm;
    initgraph(&gd, &gm, "");

    setbkcolor(LIGHTBLUE);
    cleardevice();

    /* Ground */
    setfillstyle(SOLID_FILL, GREEN);
    bar(0, 420, 640, 480);

    /* Sun */
    setcolor(YELLOW);
    setfillstyle(SOLID_FILL, YELLOW);
    circle(540, 80, 40);
    floodfill(540, 80, YELLOW);

    /* House body */
    setcolor(WHITE);
    setfillstyle(SOLID_FILL, LIGHTGRAY);
    bar(180, 220, 460, 420);
    rectangle(180, 220, 460, 420);

    /* Roof outline */
    setcolor(RED);
    line(160, 220, 320, 110);
    line(320, 110, 480, 220);
    line(160, 220, 480, 220);

    /* Roof fill */
    setfillstyle(SOLID_FILL, RED);
    floodfill(320, 160, RED);

    /* Door */
    setcolor(BROWN);
    setfillstyle(SOLID_FILL, BROWN);
    bar(295, 315, 365, 420);
    rectangle(295, 315, 365, 420);

    /* Door knob */
    setcolor(YELLOW);
    setfillstyle(SOLID_FILL, YELLOW);
    circle(350, 370, 5);
    floodfill(350, 370, YELLOW);

    /* Left window */
    setcolor(CYAN);
    setfillstyle(SOLID_FILL, CYAN);
    bar(215, 265, 275, 325);
    rectangle(215, 265, 275, 325);
    line(245, 265, 245, 325);
    line(215, 295, 275, 295);

    /* Right window */
    bar(385, 265, 445, 325);
    rectangle(385, 265, 445, 325);
    line(415, 265, 415, 325);
    line(385, 295, 445, 295);

    /* Small path */
    setcolor(LIGHTGRAY);
    setfillstyle(SOLID_FILL, LIGHTGRAY);
    bar(285, 420, 375, 480);

    setcolor(WHITE);
    outtextxy(170, 450, "House drawing using graphics.h");

    getch();
    closegraph();
    return 0;
}

4. Step-by-Step Code Explanation

Initialize graphics mode

The variables gd and gm store the graphics driver and graphics mode. The value DETECT asks the library to select a suitable driver. The call to initgraph() opens the graphics window and prepares the screen for drawing.

Draw the background and ground

The call to setbkcolor(LIGHTBLUE) gives the scene a sky color. After that, cleardevice() applies the background color. The ground is drawn with bar(0, 420, 640, 480), which fills the lower part of the screen with green.

Draw the sun

The sun is a yellow circle centered at (540, 80) with radius 40. The circle command draws the outline. The floodfill() call fills the inside with yellow. Flood fill needs the boundary color, so the third argument is also YELLOW.

Draw the house body

The main house wall is a filled rectangle from (180, 220) to (460, 420). The bar() function fills it, and rectangle() draws the outline. This combination is common in graphics.h because it gives you both color and a visible border.

Draw the roof

The roof is a triangle. Its left base point is (160, 220), its top point is (320, 110), and its right base point is (480, 220). Three calls to line() connect those points. Then floodfill(320, 160, RED) fills the enclosed roof area.

Add door and windows

The door uses a brown filled rectangle, while each window uses a cyan filled rectangle. Extra vertical and horizontal lines divide each window into four panes. These details make the house easier to recognize while keeping the program beginner friendly.

5. Ways to Customize the House

Once the basic program works, try changing one thing at a time. Move the roof higher by decreasing its y-coordinate. Make the house wider by increasing the right x-coordinate of the body. Change the window colors, add a chimney, draw clouds, or place trees beside the house.

You can also convert this static drawing into a mini scene. Use loops to draw multiple houses in a row, add random stars at night, or animate the sun by clearing and redrawing it at different positions. These are small changes, but they teach important graphics programming ideas: coordinates, layering, repainting, and shape composition.

Tip: If a fill does not appear, check whether the shape is fully closed and whether the boundary color passed to floodfill() matches the outline color.

Frequently Asked Questions

Which graphics.h function draws the roof of the house?

The roof is drawn with three line() calls. These lines connect the left base point, top point, and right base point to create a triangle.

Why is floodfill not filling my roof?

The roof must be fully closed, and the boundary color passed to floodfill() must match the actual outline color. If either is wrong, the fill may leak or fail.
